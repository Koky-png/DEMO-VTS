# VTS — Vogue Tawala Sky | Demo Store

Three pages: **Home** (`/`), **Shop** (`/shop`) and **Experience** (`/experience`). The admin prototype is at `/admin`.

## Run

1. Install Node.js 20 or later.
2. In this folder: `npm install`
3. Start: `npm run dev`
4. Visit `http://localhost:3000`.

## What's included
- Dark-and-gold responsive storefront with user-supplied hero photo
- 13 browseable categories and user-supplied bottle photographs, including nine new wines and Tequila Rose
- Interactive keyword search, category filters and locally stored demo cart
- Fictional prices and stock amounts exclusively for testing
- Location wording: Utawala, opposite Ballmaina Shell when approaching from Ruai
- Age confirmation gate. This is not a legally sufficient checkout or delivery-age verification.

## Not live yet
Real checkout, M-Pesa payments, Glovo delivery, order fulfillment and production administrative security must be implemented and verified before the site accepts orders. Never treat demo prices as verified store prices. Admin features require a Supabase project and proper authentication; follow README and `.env.example`.

**Site is a preview/prototype**, not a production-verified shop.
